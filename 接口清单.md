# MCP接口清单（23项）

此表列出本包实际工具及参数。支持范围以功能说明为准；接口存在不代表对任意工程可用。

## `mcgs_detect_environment`

`mcgs_detect_environment()`

Inspect MCGS installation files, PE bitness, installed versions and COM registry entries. No COM activation.

## `mcgs_get_capabilities`

`mcgs_get_capabilities()`

List configured aliases and exact experimental capability boundaries without connecting to devices.

## `mcgs_get_screen_snapshot`

`mcgs_get_screen_snapshot()`

Read a recent host-captured MCGS editor selection. Not a live stream or complete object enumeration.

## `mcgs_plan_label_text_change`

`mcgs_plan_label_text_change(expected_text: str, new_text: str)`

Plan replacement of the selected label's text in its open extended-properties dialog. No GUI mutation.

## `mcgs_apply_screen_plan`

`mcgs_apply_screen_plan(plan_id: str)`

Back up disk project and QUEUE a one-shot label-edit job. An attended host must execute and verify it.

## `mcgs_get_screen_job`

`mcgs_get_screen_job(job_id: str)`

Read host execution receipt. Only reopened_verified confirms text read after closing/reopening the screen.

## `mcgs_probe_native_editor`

`mcgs_probe_native_editor(project_alias: str)`

Attach to the live editor's COM ROT DataCentre and read project/windows/count. No UI or COM activation. Not a control collection.

## `mcgs_list_screen_controls`

`mcgs_list_screen_controls(project_alias: str, screen_name: str)`

Read saved MCE directly; list supported static labels only. Partial coverage, not live/unsaved canvas objects. No GUI.

## `mcgs_get_control`

`mcgs_get_control(project_alias: str, screen_name: str, control_name: str)`

Read named static label text/bounds directly from saved MCE. Reject unsupported or ambiguous controls; no GUI fallback.

## `mcgs_plan_control_change`

`mcgs_plan_control_change(project_alias: str, screen_name: str, control_name: str, expected_source_sha256: str, new_text: str | None=None, new_bounds: dict[str, int] | None=None)`

Plan a named static-label derivative-file change. Text must retain GBK byte length; bounds use x/y/width/height. No GUI.

## `mcgs_apply_control_change_copy`

`mcgs_apply_control_change_copy(plan_id: str)`

Create NEW MCE copy with the planned static label changes; reparse/compare all tables. Never overwrite source or update live editor.

## `mcgs_list_functional_controls`

`mcgs_list_functional_controls(project_alias: str, screen_name: str)`

Read measured existing button release bindings and flow condition/speed/direction from saved MCE. Partial coverage. No GUI.

## `mcgs_plan_functional_change`

`mcgs_plan_functional_change(project_alias: str, screen_name: str, control_name: str, expected_source_sha256: str, changes: dict[str, Any])`

Plan existing functional binding changes. Button: variable, operation=set_one/set_zero (release only).
Flow: variable_replacements mapping, speed=fast/medium/slow, direction=forward/reverse,
block_length, block_gap, edge_margin. Condition polarity and stopped-drawing flags remain unmapped/preserved.
Existing variables of same type and same GBK expression length only. Preserves compiled operators.
Apply with mcgs_apply_control_change_copy; never writes source or live editor.

## `mcgs_get_project_snapshot`

`mcgs_get_project_snapshot(project_alias: str)`

Read configured project file metadata and SHA-256. Does NOT extract variables, scripts or button bindings.

## `mcgs_backup_project`

`mcgs_backup_project(project_alias: str)`

Create a new verified byte copy. Save/close the MCGS editor first for application consistency.

## `mcgs_get_script`

`mcgs_get_script(script_alias: str)`

Read an explicitly configured exported script text file. Does not read the live MCGS editor.

## `mcgs_analyze_script`

`mcgs_analyze_script(text: str)`

Review IF/ELSE/ENDIF balance heuristically; this is NOT an MCGS compiler or control safety analysis.

## `mcgs_plan_script_change`

`mcgs_plan_script_change(script_alias: str, new_text: str)`

Plan an exported-text-only replacement, returning a diff and revision hashes. No target file write.

## `mcgs_apply_script_change`

`mcgs_apply_script_change(plan_id: str)`

Apply a pending exported-text plan with backup, stale-revision check and readback. Does NOT update .mce.

## `mcgs_discard_script_plan`

`mcgs_discard_script_plan(plan_id: str)`

Discard a pending in-memory script replacement plan.

## `mcgs_read_tags`

`mcgs_read_tags(names: list[str])`

Read 1-32 configured Modbus tag aliases. Sequential channel samples, not a full project variable list.

## `mcgs_write_tag`

`mcgs_write_tag(name: str, value: int | float | bool)`

Write one configured writable tag, with no request retries and immediate readback. Inspect returned status.

## `mcgs_observe_expected_tags`

`mcgs_observe_expected_tags(expected: dict[str, int | float | bool], timeout_seconds: float=5.0)`

Poll mapped values until equal to encoded expectations or timeout. No action requests are sent.
