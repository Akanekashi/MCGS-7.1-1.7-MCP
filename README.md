# 能实现的功能

## 1. 环境检测与工程连接

检查MCGS安装文件、位数和COM注册信息；通过正在运行的编辑器的COM运行对象表，读取工程路径、用户窗口名称和数据对象数量。不激活新的COM实例，未获得实时画布控件集合，也不能直接读写未保存的控件属性。

## 2. 工程文件信息与备份

读取配置工程的大小、SHA-256与Jet容器标识；生成独立备份并核对字节哈希。该接口不提取完整工程语义。备份一致性以磁盘保存状态为准，打开中的编辑器可能有未保存内容。

## 3. 导出脚本文本

读取显式配置的TXT/BAS/MCGSSCRIPT文本，生成修改差异与计划，备份后写回并校验，或丢弃计划。提供IF/ELSE/ENDIF结构启发式检查。**这些操作不修改MCE内脚本，也不等于MCGS语法编译或自动导入。**

## 4. Modbus通信

按照配置别名读写寄存器或线圈；支持bool、uint16/int16、uint32/int32和float32，提供字节/字顺序、范围检查及写后回读。可轮询等待预期值。MCGS通道地址按1起算配置。

需要先在MCGS中配置通信驱动、对应通道、变量和服务端地址，服务器不会自动建立变量映射。已与本机MCGS模拟器联调，真实TPC与现场设备未验证；新空工程未配置通信映射时无法直接读写变量。

## 5. 已测格式的控件副本修改

从已保存MCE直接读文件，不通过鼠标点击来写控件。按画面名与控件名定位，先返回修改计划，再发布新MCE副本。修改同时核对变量名与内部索引，发布前重新解析并比对所有表。

| 控件 | 已实现的受限属性 |
|---|---|
| 静态标签 | 等GBK字节长度文字替换，位置和尺寸 |
| 标准按钮 | 已有抬起动作的绑定开关变量，置1/清0；当前测得的8字节GBK变量名与特定359字节属性布局 |
| 流动块 | 已有条件表达式中的同类型变量替换，同时更新编译索引；快/中/慢，正向/反向，长度、间隔、侧距 |

限制：变量必须已经存在；条件表达式总GBK字节长度不变，保留原运算逻辑；重名控件、重复物理记录或碎片拒绝写入。仅新副本写入，不覆盖源工程或同步到实时编辑器。调用成功返回文件验证，不代表原生打开、编译或运行已通过。

**控件适配器是针对先前水务工程测得的布局，不能推广到所有MCGSE7.7工程。新建工程测试因窗口归档格式不匹配而失败。**

## 6. 保留的旧界面桥接

另有4个早期桥接工具，依赖外部有人值守的界面宿主提供快照和任务回执。默认关闭，队列成功不代表实际编辑成功。本包不包含该宿主及其电脑操作工具；不建议把它当成直接控件API。
